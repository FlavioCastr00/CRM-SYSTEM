# CRM-SYSTEM

This project develops a CRM (Customer Relationship Management) application. It aims to store, organize, display and keep track of companies, contacts and tasks. Later, this system will expand to implement lead discovery features, including crawlers, which will gather contact data from companies based on a search term. 

## Technologies
- Node.js
- SQLite
- better-sqlite3
- express

## Dependencies Installation

Use the following PowerShell command to install all dependencies

```powershell
npm install
```

## How to Initialize the Database

To initialize the database, simply run the following command in PowerShell:

```powershell
node database/init.js
```
